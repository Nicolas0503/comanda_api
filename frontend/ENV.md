# Variáveis de Ambiente

Copie o arquivo `.env.example` para `.env` e configure as variáveis conforme necessário.

## Variáveis Disponíveis

- `VITE_API_URL` - URL base da API (padrão: https://127.0.0.1:8443)
- `VITE_APP_NAME` - Nome da aplicação (padrão: Comandas do Zé)

## Exemplo de Uso

```bash
cp .env.example .env
```

Depois edite o arquivo `.env` com suas configurações.
